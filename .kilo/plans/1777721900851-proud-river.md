# Plan d'implémentation

Objectif : ajouter le zoom/dézoom BR à l'export, améliorer sélection et clipboard texte/ligne, ajouter mute/unmute, et corriger le chevauchement lors de la création/redimensionnement de lignes.

## 1. Export : scale X/Y de la BR

- Étendre `src/ui/export_modal.rs` :
  - agrandir la carte et ajouter un réglage `scale` ou `br_scale` avec boutons `-` / `+` et valeur affichée, par exemple `100%`, bornée autour de `50%..200%`.
  - retourner `Export { fps, br_scale }` au lieu de seulement `fps`.
  - ajouter les clés i18n `export_modal.br_scale` dans `i18n/fr.toml` et `i18n/en.toml`.
- Étendre `UiAction::StartExport` dans `src/ui/widget.rs` avec `br_scale: f32`, puis adapter `src/ui/mod.rs` et `src/main.rs`.
- Introduire un paramètre d'export commun, minimalement en passant `br_scale` à `video_export::export_mp4`.
- Adapter `src/video_export.rs` :
  - calculer la hauteur de BR via une fonction prenant `br_scale`.
  - transmettre `br_scale` aux rendus GPU et CPU.
- Adapter `src/rythmo_cpu_renderer.rs` et `src/rythmo_gpu_renderer.rs` :
  - le scale doit agir sur X et Y du texte et de la géométrie BR, pas uniquement sur l'espacement horizontal.
  - pour “dézoomer et voir plus loin”, appliquer le facteur au `PIXELS_PER_FRAME`, aux hauteurs, polices, badges, ticks et playhead dans le rendu export.
  - garder la largeur vidéo export inchangée ; la BR rendue devient plus dense si `br_scale < 1.0`, ce qui montre plus de frames/mots autour du playhead.

## 2. Sélection de mots/textes par clics répétés

- Étendre `src/ui/text_input.rs` avec helpers de sélection :
  - `select_range(start, end)`.
  - `select_word_at(text, pos)` basé sur limites Unicode `char` et séparateurs whitespace/punctuation.
  - optionnel : `selected_text(text)` pour le clipboard.
- Adapter `src/ui/rythmo.rs` :
  - sur double-clic dans une ligne déjà en édition, sélectionner le mot entier au lieu de simplement positionner le curseur.
  - traiter les clics répétés (“spam clic gauche”) comme double-clics existants via la détection `main.rs`, donc le comportement devient naturel sans nouveau timer.
  - pour badge personnage : double-clic ou clic répété sur le badge ouvre l'édition et sélectionne tout le nom (`char_input.select_all`).
  - conserver CTRL+A existant pour `char_input`, `line_input`, `note_input`.
- Ajouter le rendu de sélection du nom personnage : actuellement seul le curseur badge est dessiné ; ajouter un rectangle de sélection sur le badge quand `char_input.selection_range()` existe.

## 3. Clipboard texte : copier/couper/coller

- Compléter les fonctions clipboard dans `src/main.rs` :
  - il existe `clipboard_paste`; ajouter `clipboard_set(text)` Windows et stub non-Windows.
  - gérer `Ctrl+C`, `Ctrl+X`, `Ctrl+V` lorsque `state.is_editing_text()`.
- Ajouter des événements `UiEvent::Copy`, `UiEvent::Cut`, éventuellement `Paste(String)` ou réutiliser `KeyInput` pour coller.
- Dans `src/ui/rythmo.rs` :
  - `Copy` retourne une `UiAction::SetClipboard(String)` ou une action dédiée pour que `main.rs` écrive dans le presse-papiers.
  - `Cut` copie puis supprime la sélection via `UpdateLineText`, `UpdateCharacterName` ou `UpdateLineNote` selon le champ actif.
  - `Paste` remplace la sélection ou insère au curseur en utilisant la logique existante de `TextInputState::handle_key`.
- Garder l'undo/redo cohérent via les actions existantes `UpdateLineText`, `UpdateCharacterName`, `UpdateLineNote`.

## 4. Clipboard ligne complète / boîte complète

- Ajouter un clipboard applicatif dans `State` ou `Ui` pour une `RythmoLine` clonée, distinct du presse-papiers texte OS.
- Étendre `UiAction` avec :
  - `CopySelectedLine`, `CutSelectedLine`, `PasteLineAtSelectionOrFrame` ou équivalent.
- Dans `main.rs`, hors édition texte :
  - `Ctrl+C` sur `Selection::Line(id)` copie la ligne entière.
  - `Ctrl+X` copie puis supprime via la commande existante de suppression.
  - `Ctrl+V` colle une nouvelle boîte, idéalement à la frame courante et sur le même `y_slot` que l'original, avec nouvel id.
- Ajouter dans `Project` une méthode type `duplicate_line_from(snapshot, start_frame)` ou utiliser `insert_line` avec un nouvel id construit côté `State`.
- Ajouter une commande undoable pour le collage : réutiliser `Command::CreateLine { line_id }` si la ligne est déjà insérée, car undo supprimera la ligne.
- Lors du collage texte depuis une ligne sélectionnée vers une autre ligne de réplique :
  - si une ligne est sélectionnée et qu'une autre ligne est en édition, `Ctrl+V` insère le texte OS normalement.
  - si hors édition et sélection ligne, `Ctrl+V` colle la boîte complète.

## 5. Mute/unmute audio dans la toolbar

- Ajouter les icônes à l'atlas :
  - `src/ui/icons.rs` inclut `sound.svg` et `mute.svg`.
  - `src/ui/mod.rs` ajoute `sound` et `mute` dans `icon_names`.
- Ajouter `UiAction::ToggleMute`.
- Dans `Ui`, stocker `last_nonzero_volume: f32` ou dans `State` si nécessaire.
- Toolbar : placer un bouton icône juste avant le slider volume.
  - icône `sound` si volume > 0, `mute` si volume == 0.
  - clic : si volume > 0, mémoriser et passer à `0.0`; sinon restaurer le dernier volume ou `0.75`.
  - reconstruire la toolbar après changement de volume/mute pour mettre l'icône à jour.
- Ajouter i18n tooltip `toolbar.mute` / `toolbar.unmute`.

## 6. Chevauchement à la création puis réduction

- Inspecter et corriger le comportement dans `src/ui/rythmo.rs` et `src/state.rs` :
  - la création actuelle `CtrlClick -> CreateLine` ajoute une durée par défaut sans collision explicite.
  - le redimensionnement modifie seulement la ligne ciblée, donc le déplacement de la ligne du dessous vient probablement d'une logique de sélection/drag ou d'un évitement de collision ailleurs à confirmer pendant implémentation.
- Implémentation prévue si aucun gestionnaire caché n'est trouvé :
  - à la création d'une ligne qui chevauche une autre sur le même slot, ne pas déplacer les lignes existantes.
  - redimensionner seulement la nouvelle ligne, en clampant sa durée si nécessaire pour éviter de dépasser sur la ligne suivante, ou autoriser le chevauchement sans side-effect selon le comportement actuel.
  - le correctif minimal : toute action `ResizeLine` ne doit muter que la ligne `id`, jamais les autres lignes du même `y_slot`.
- Ajouter une vérification manuelle ciblée : créer une ligne chevauchante puis réduire la nouvelle depuis un handle ; contrôler que la ligne existante garde `start_frame`, `duration_frames`, `y_slot`.

## 7. Vérification

## Risques / points à surveiller

- Clipboard Windows : bien gérer `GlobalAlloc`, UTF-16 nul-terminé et `SetClipboardData` sans fuite.
- Rendu GPU export : le cache texte doit intégrer la taille de police effective dans le hash, sinon le changement de scale pourrait réutiliser une texture incorrecte.
- Le rendu de sélection personnage utilise des largeurs approximatives (`BADGE_CHAR_W`) ; acceptable dans le style actuel, mais à ajuster si visuellement trop décalé.
- Le collage de boîte complète doit générer un nouvel id et rester undoable.
