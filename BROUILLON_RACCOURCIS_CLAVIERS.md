## Explorateur de fichiers du projet

| Raccourci | Action |
|---|---|
| `Ctrl + L` | Ouvrir ou fermer les fichiers du projet depuis l’espace Rythmo |
| `Tab` / `Maj + Tab` | Parcourir les éléments de l’arborescence |
| `↑` / `↓`, `Début` / `Fin`, `Page haut` / `Page bas` | Déplacer la sélection |
| `←` / `→` | Replier/déplier les groupes et naviguer dans la hiérarchie |
| `Entrée` / `Espace` | Activer l’élément sélectionné |
| `F2` | Renommer l’élément sélectionné |
| `Suppr` | Retirer l’élément sélectionné du projet |
| `Maj + F10` | Ouvrir le menu contextuel |
| `Échap` | Fermer le panneau ou le menu contextuel |
